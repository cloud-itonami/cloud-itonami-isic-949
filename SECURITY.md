# Security Policy

## Scope Boundaries

This actor operates within permanent, non-overridable scope boundaries. Proposals touching the following are rejected:

- Membership-eligibility or expulsion decisions
- Religious doctrine or belief content
- Political positions or advocacy stances
- Dues amounts or financial waivers
- Disciplinary action

## Verification

All members and events must be independently verified in the store before any proposal can commit or escalate.

## Escalation Requirement

All proposals are **proposals only** (`:propose` effect). No auto-commits without escalation for review.

## Reporting

Report security concerns via the superproject governance process.
